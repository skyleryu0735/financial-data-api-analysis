# Financial Data API Analysis

A Python project that retrieves financial market data through external APIs and transforms raw API responses into structured data for analysis.

## Tools
- Python
- Pandas
- Requests
- REST APIs
- JSON
- Jupyter Notebook

## Workflow
1. Connect to an external financial data API
2. Send HTTP requests and retrieve JSON responses
3. Parse API responses into Pandas DataFrames
4. Clean and validate market data
5. Perform exploratory analysis and visualization

## Concepts Practiced
- REST API requests
- JSON parsing
- Environment variables
- API key management
- Data cleaning
- Financial time-series data

## Security
API credentials are stored locally using environment variables and are not included in this repository.
